HOW THE PILOT WORKSIN THE INTERACTIVE APPLICATION

Start here · What is this application?

Scientific English Agents is a formative learning environment. Six specialised agents support scientific writing, reasoning, vocabulary, oral communication, language accuracy and assessment. They guide your revisions rather than completing your work.

The pilot requires Mistral configuration for live responses. AI feedback always requires professional judgement.

How to use it

  1. Choose an agent using the buttons below.
  2. Select your CEFR level and scientific field.
  3. Enter a short, anonymised text or question.
  4. Confirm the data notice and submit.
  5. Review the feedback and ask follow-up questions.

03 / Our approach

Not answers.
Better questions.

Scientific English is more than vocabulary. It requires reasoning, uncertainty, disciplinary conventions and the ability to communicate evidence responsibly.

Our aim is to make AI a partner in the learning process — not a substitute for scientific judgement.

04 / Design principles

Built for learning.
Designed for trust.

01 — PEDAGOGY FIRST

Meaning before fluency.

Language support should strengthen disciplinary understanding and scientific reasoning.

02 — HUMAN IN CONTROL

Agency, not automation.

Students and educators retain responsibility for decisions, interpretation and final work.

03 — TRANSPARENT PILOT

Test. Reflect. Improve.

Evaluate usefulness, usability and limitations before considering wider deployment.

05 / Responsible use

Scientific work deserves care.

Do not submit identifiable student data, patient information, unpublished sensitive research or confidential documents. Submissions entered in the interactive application are sent to the configured Mistral service. This static website does not process scientific submissions.
