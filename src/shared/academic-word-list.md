## High-Value Verbs for Scientific Writing
(Cross-sublist selection — prioritise for active teaching)

| Function | Verbs |
|----------|-------|
| Reporting | indicate, suggest, demonstrate, reveal, show, confirm |
| Evaluating | assess, evaluate, examine, investigate, analyse |
| Comparing | contrast, differ, resemble, vary, correspond |
| Concluding | conclude, determine, establish, identify, propose |
| Describing change | increase, decrease, fluctuate, peak, decline |
| Describing process | comprise, consist, involve, undergo, yield |

## Common AWL Collocations
- significant + difference / increase / reduction / correlation
- previous + studies / research / findings / work
- current + study / evidence / understanding / debate
- further + investigation / research / analysis / work
- consistent + with / findings / results / evidence
