# Pedagogy — Theoretical Foundations

## 1. Genre-Based Approach to Scientific Writing

This skill is built on **genre theory** (Swales, 1990; Bhatia, 1993):
scientific texts are not neutral containers for information — they are
socially constructed rhetorical acts with predictable structures, moves,
and linguistic conventions. Teaching genre means teaching writers to
participate in disciplinary discourse communities.

**Core genre:** IMRAD (Introduction, Methods, Results, and Discussion) —
the dominant structure in natural sciences, medicine, and engineering.

**CaRS model** (Create a Research Space — Swales, 1990): the three-move
structure for Introductions used by the Writing Coach agent.

---

## 2. Competency-Based Approach (APC — Approche Par Compétences)

Rather than content coverage, this system targets **observable competencies**:
things students can demonstrably *do* in scientific English.

Each competency (WP1–WP6, OM1–OM4, CR1–CR4, LC1–LC5) maps to:
- a CEFR level descriptor (see `src/shared/cefr-descriptors.md`)
- at least one agent protocol
- at least one rubric criterion

Assessment asks: *Has this competency been demonstrated?* (validated / in
progress / not yet achieved) — not *What grade does this text get?*

---

## 3. Formative Assessment and Feedback Design

The **PPP protocol** (Praise → Problem → Proposal) is grounded in:
- Hattie & Timperley (2007): feedback is most effective when it identifies
  the gap between current and target performance *and* provides a path forward
- Black & Wiliam (1998): formative assessment significantly raises achievement
  when it includes specific, actionable feedback

Design constraints:
- Maximum 2 feedback points per session (cognitive load management)
- Micro-task assigned at end of every session (spaced practice)
- Memory block tracks patterns across sessions (longitudinal diagnosis)

---

## 4. Vocabulary Acquisition

The **Academic Word List** (Coxhead, 2000) provides the cross-disciplinary
vocabulary core. Domain-specific vocabulary banks (currently embedded directly
in `src/agents/lexical-expert/agent.md`; additional community-contributed banks
may be added under `src/agents/lexical-expert/domain-banks/` -- see
doc/contributing.md) supplement it with field-specific terminology.

Research basis: Nation (2001) — vocabulary learning requires multiple
exposures in meaningful contexts. The collocation trainer and register repair
protocols create these exposures within authentic scientific texts.
